# Changelog

All notable changes to Ascendra UI are documented here.

Format: `## [version] — description`. Breaking changes are marked **Breaking**.

---

## [1.0.0] — Initial release

### Added
- Full component library under `ascendra-ui/` — layout, forms, data display, feedback, navigation, and chart components
- App shell: `PageLayout`, `Header`, `Nav`, `SideBar`, `ContentArea`
- `scripts/init.js` — one-time consumer project setup
- `scripts/upgrade.js` — upgrade component library and docs from source repos
- `scripts/release.js` — internal release tool (removed from consumer projects by `init.js`)
- Getting started page (`/`) and sandbox page (`/sandbox`)
- `ascendra.json` version lock file
